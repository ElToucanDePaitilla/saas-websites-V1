# Module « Bandeau défilant » (marquee / infinite carousel)

**Objectif :** ajouter une **nouvelle famille de module** `marquee` : un ruban de photos qui défile en boucle continue, avec hauteur de bande et de vignettes réglables, ratio unifié, ombre du Design System, fond couleur du thème, pause au survol, animation d'entrée standard et destination unique cliquable sur le ruban.

**Périmètre :** domaine `src/lib/pages.ts`, rendu public `src/components/modules/marquee/*`, CSS `src/app/globals.css` (premier `@keyframes` du projet), éditeur `src/components/backoffice/pages/modules/ModuleMarqueeEditor.tsx`, points d'intégration de famille (enum DB + Zod + icône + catalogue + 2 routeurs), loaders SEO/OG `src/lib/public-page.ts`, `/demo`, migration Drizzle.

## 2. Rendu public — `src/components/modules/marquee/MarqueeModule.tsx`

Server Component. Reçoit `module: PageModule`.

- `const content = resolveMarqueeContent(raw)` ; `visible = content.images.filter((i) => i.url !== "" && i.hidden !== true)` ; si `visible.length === 0` → `return null`.
- `tileWidth = Math.round(content.tileHeight * (ratioWidth / ratioHeight))` pour le `sizes` de `MediaImage` (`sizes={`${tileWidth}px`}`).
- **Deux groupes identiques** de la liste complète : le second `aria-hidden="true"` (évite le double lecture d'alt par les lecteurs d'écran).
- Chaque vignette : `.marquee__tile` (position relative, `height`, `aspect-ratio` en style inline, `boxShadow` = `galleryShadowStyle(content.style.shadow)` si `shadowEnabled`, sinon `"none"`) contenant `MediaImage fill sizes className="object-cover"`. `alt` = `image.alt || "Photo du portfolio"`.
- **Lien** (si `linkEnabled && linkHref.trim() !== ""`) : l'élément qui remplace le `<div class="marquee__viewport">` est
  - `<NavLink className="marquee__viewport" href={linkHref} ariaLabel={linkLabel.trim() || undefined}>` pour tout `href` ordinaire (interne, ancre, `http(s)` → `NavLink` gère déjà le nouvel onglet) ;
  - `<a className="marquee__viewport" href={linkHref}>` pour `mailto:`/`tel:`.
  - La zone cliquable est **le viewport du ruban uniquement** ; le fond de section reste inerte. Aucun descendant interactif dans le lien (HTML5 transparent autorise un `<div>` sous `<a>`).
- Structure :
  ```
  <section id={anchorId} class="marquee [marquee--pause]" style={vars}>
    <RevealHero animation={module.animation}>
      <div|a class="marquee__viewport">
        <div class="marquee__group">…vignettes…</div>
        <div class="marquee__group" aria-hidden="true">…mêmes vignettes…</div>
      </div|a>
    </RevealHero>
  </section>
  ```
- Variables CSS inline : `--marquee-bg` (`bannerColorCssValue(content.style.background)`), `--marquee-height`, `--marquee-tile-height`, `--marquee-aspect` (`marqueeAspectRatio`), `--marquee-gap`, `--marquee-duration`. Idiome `type CSSVars = CSSProperties & Record<\`--${string}\`, string>` (`CardItem.tsx:41`).
- Aucun `h1`/`h2` : le module ne porte aucun chapitre.

## 3. CSS — `src/app/globals.css`

Nouvelle section `MODULE « BANDEAU DÉFILANT »` après le contact-map, **hors `@layer`**, avant `Base layer` :

```css
.marquee {
  display: flex;
  align-items: center;            /* centrage vertical du ruban */
  height: var(--marquee-height, 350px);
  overflow: hidden;               /* rognage symétrique si vignette plus haute */
  background-color: var(--marquee-bg, var(--bg-color));
}
.marquee__viewport { flex: 1 1 auto; min-width: 0; display: flex; overflow: hidden; cursor: default; }
.marquee__group {
  display: flex;
  flex: 0 0 auto;
  min-width: 100%;                /* garantit un demi-ruban au moins large que la bande */
  justify-content: space-around;
  gap: var(--marquee-gap, 20px);
  padding-right: var(--marquee-gap, 20px); /* conserve l'écart au raccord */
  will-change: transform;
  animation: marquee-scroll var(--marquee-duration, 40s) linear infinite;
}
.marquee__tile {
  position: relative;
  flex: 0 0 auto;
  height: var(--marquee-tile-height, 250px);
  aspect-ratio: var(--marquee-aspect, 2 / 3);
  overflow: hidden;
  border-radius: 2px;
  background: var(--surface-color);
}
@keyframes marquee-scroll { to { transform: translate3d(-100%, 0, 0); } }

.marquee--pause:hover .marquee__group,
.marquee--pause:focus-within .marquee__group { animation-play-state: paused; }

@media (prefers-reduced-motion: reduce) {
  .marquee__group { animation: none; }
  .marquee__group[aria-hidden="true"] { display: none; } /* un seul jeu, tous les visuels restent lisibles */
  .marquee__viewport { overflow-x: auto; }
}
```

Pourquoi deux groupes animés `-100%` plutôt qu'une piste unique `-50%` : chaque groupe fait **au moins la largeur de la bande** (`min-width: 100%`), donc aucune zone vide ne peut apparaître au raccord, même avec deux photos, et cela sans mesurer la largeur en JavaScript. `space-around` étale les listes courtes (l'écart réglé devient un minimum) — compromis assumé pour ne jamais montrer de trou.

## 9. Risques et pièges

- **Premier `@keyframes` du projet** : vérifier que Lightning CSS le conserve (forme exacte du chunk servi) et que `prefers-reduced-motion` neutralise bien l'animation.
- **Groupes strictement identiques** : ne jamais différencier le second groupe (index, `priority`, effet) — la boucle suppose des largeurs et contenus égaux. Le second groupe est toujours `aria-hidden`.
- **Liste courte** : `space-around` étale les vignettes (l'écart réglé devient un minimum) — pas de trou, mais espacement élargi. Assumé.
- **Vignette plus haute que la bande** : rognage symétrique voulu (D11) ; l'aide de l'éditeur le signale.
- **`NavLink` sous `<a>`** : ne pas imbriquer d'élément interactif dans le lien ; le ruban n'en contient aucun.
- **`mailto:`/`tel:`** : ne pas passer par `NavLink` (il les traiterait comme des routes) — `<a>` simple, comme `CTAButton.tsx:49`.
- **Images `hidden`/sans URL** : exclues du rendu **et** de la collecte SEO (`collectImageUrls`).
- **`will-change: transform`** sur un élément toujours animé : une seule couche GPU par module, ne pas l'ajouter ailleurs.
- **`publicDescription`** : pas de texte dans ce module — ne pas y ajouter de branche.
- **Comptages HTML** : mesurer par tranche et par sélecteur complet (la charge RSC de `next dev` duplique les classes).
